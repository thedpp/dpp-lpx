# How we use audio with different languages

LPX does not create bespoke language tags.

Audio language tagging is a standard method for identifying human languages in internet-based media, using two letter codes primarily based on ISO 639 in conjunction with ISO 3166 country code for regional variants.

A good reference resource is http://www.lingoes.net/en/translator/langcode.htm

An example is cy-GB, where Welsh is cy taken from ISO 639, and GB is the country code taken from ISO 3166.
